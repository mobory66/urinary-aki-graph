# 肾功能不全与急性肾损伤 · 知识图谱与问题图谱（模块二）

> 泌尿整合课程「师—生—机」协同教改作品 · 2024 级基础医学班 · 模块二
>
> 在线访问：**<https://mobory66.github.io/urinary-aki-graph/>**

## 作品简介

本页是一个可交互的**单文件网页**（无外部依赖、可离线打开），以「生理—病生—病理—药理—临床」五层结构，
系统梳理**肾功能不全的基本发病环节**与**急性肾损伤（AKI）**的知识图谱与问题图谱，并配套病例情境、学习工具与设计说明。
医学内容逐条对照人卫第 10 版教材、KDIGO 等指南与 Europe PMC 文献人工核对后发布。

## 页面功能

- **知识图谱**：导览视图（按 7 个学科阶段总览）、完整图谱（可缩放/拖动/点击节点看机制链与文献/点击连线看关系）、大纲视图；
  另支持「学习路径漫游」8 步自动定位、「找路径」任意两节点最短关系链、关联深度与关系类型筛选、小地图、全屏与键盘导航。
- **问题图谱**：矩阵视图（层级 × 类型）、关系视图（前置/进阶/相似关系）；自测模式可先自答再看解析并标记掌握，支持随机抽题与进度保存在本机。
- **病例情境**：7 个真实情境，从主诉、检查到处理要点，串联病理—病生—药理决策，并可跳回知识节点与问题。
- **学习工具**：eGFR 计算器（CKD-EPI 2021）、KDIGO AKI 分期判定、FENa/FEUrea 判读、鉴别速查表、AKI 预防与透析指征清单。
- **设计说明**：AI 工具与人工审核、设计思路、使用说明、特点、评分自查、参考文献与版本记录。
