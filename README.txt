模块二发布包 · 肾功能不全的基本发病环节与急性肾损伤
====================================================

文件：index.html —— 单文件网页（含全部内容，无外部依赖）

一、上传到独立仓库（GitHub Pages）
1. 登录 GitHub，新建 Public 仓库，名称建议：urinary-aki-graph
   （如果改用其他名称，提交网址相应变为 https://mobory66.github.io/<仓库名>/）
2. 仓库首页 → Add file → Upload files → 选择本文件夹的 index.html → Commit changes
3. 仓库 Settings → Pages → Build and deployment：
   Source 选 "Deploy from a branch"；Branch 选 main，目录选 /(root) → Save
4. 等待约 1 分钟，访问并核对：
   https://mobory66.github.io/urinary-aki-graph/
5. 作业板块提交该网址 + 简要说明（见 module2/docs/提交说明·急性肾损伤.md）

二、让模块一与模块二互相切换
本页顶部与页脚已有「⇄ 模块一」按钮，指向
https://mobory66.github.io/urinary-water-electrolyte-graph/
模块一页面也需要更新到 v1.1：把本项目根目录的 index.html（v1.1）
上传覆盖模块一仓库（urinary-water-electrolyte-graph）根目录的旧 index.html，
两页即可双向切换。

三、本地打开
直接双击 index.html 即可离线浏览，功能与线上一致。
